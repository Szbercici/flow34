🔐 !!!!! AUTHENTIKÁCIÓ !!!!!

Felhasználó regisztrálása:
ENDPOINT - POST -> /api/auth/register
JSON:
{
"username": "string",
"email": "string",
"password": "string"
}

---------------------------------------------

Felhasználó bejelentkezése:
ENDPOINT - POST -> /api/auth/login
JSON:
{
"username": "string",
"password": "string"
}

Működés:
Bejelentkezés után cookie-ba kerül:
access_token (rövid élettartam), refresh_token (hosszabb élettartam, kb. 14 nap)

---------------------------------------------

Új ACCESS token lekérése REFRESH tokentől:
ENDPOINT - POST -> /api/auth/refresh

Feltétel:
érvényes refresh token

---------------------------------------------

Felhasználó logout:
ENDPOINT - POST -> /api/auth/logout

Feltétel:
érvényes access token

---------------------------------------------

👤 !!!!! FELHASZNÁLÓK !!!!!

Bejelentkezett felhasználó lekérése:
ENDPOINT - GET -> /api/users/me

Feltétel:
bejelentkezett felhasználó

JSON:
{
"id": number,
"username": "string",
"email": "string"
}

---------------------------------------------

Felhasználó lekérése username alapján:
ENDPOINT - GET -> /api/users/{username}

---------------------------------------------

Összes felhasználó lekérése:
ENDPOINT - GET -> /api/users/all

Feltétel:
ADMIN

---------------------------------------------

ADMIN

🛒 !!!!! TERMÉKEK !!!!!

📦 !!!!! RENDELÉSEK !!!!!

Rendelés létrehozása:
ENDPOINT - POST -> /api/orders

Feltétel:
bejelentkezett felhasználó

JSON:
{
"address": "string",
"items": [
{
"productId": number,
"quantity": number,
"price": number
}
]
}

Válasz:
{
"success": true,
"orderId": number
}

---------------------------------------------

Egy rendelés lekérése:
ENDPOINT - GET -> /api/orders/{orderId}

Feltétel:
bejelentkezett felhasználó
csak a saját rendelés kérhető le

---------------------------------------------

Felhasználó rendeléseinek listája:
ENDPOINT - GET -> /api/orders

Feltétel:
bejelentkezett felhasználó

JSON válasz:
[
{
"orderId": number,
"address": "string",
"createdAt": "2026-03-18T12:00:00"
}
]

🔐 AUTH FONTOS MEGJEGYZÉSEK:

NEM KELL Authorization header
NEM kell token localStorage-ben
Minden auth cookie alapú

Frontend fetch:
fetch(url, {
credentials: "include"
});

❗ HTTP VÁLASZOK:

200 -> Sikeres
201 -> Létrehozva
400 -> Hibás input
401 -> Hibás login
403 -> Nincs jogosultság/token
404 -> Nem található
