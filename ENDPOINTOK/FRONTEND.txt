!!!!!! FELHASZNÁLÓ KEZELÉS: !!!!!!!!

Felhasználó regisztrálása:

ENDPOINT - POST -> /api/auth/register
JSON:	{

	"username": "string",
	"email": "string,
	"password": "string"

	}

-----------------------------------------

Felhasználó bejelentkezése:

ENDPOINT - POST -> api/auth/login
JSON:	{

  	"username": "string",
 	"password": "string"

	}

Működés:
-Bejelentkezés után cookie-ba kerül:
	access_token (rövid élettartam), refresh_token (hosszabb élettartam, kb. 14 nap)

----------------------------------------

Új ACCES token lekérése REFRESH tokentől:

ENDPOINT - POST -> api/auth/refresh

Feltétel: érvényes refresh token

----------------------------------------

Felhasználó logout:

ENDPOINT - POST -> api/auth/logout

Feltétel:
Érvényes Acces token

----------------------------------------

!!!!!!!! FELHASZNÁLÓ ADATOK LEKÉRÉSE: !!!!!!!!

Bejelentkezett felhasználók lekérése:
ENDPOINT - GET ->  api/users/me

JSON:	{

 	"id": number,
  	"username": "string",
  	"email": "string"

	}
Ha nincs tokenje, akkor 404 válasz.(magyarán nincs bejelentkezve)

--------------------------------------

Felhasználó lekérése username alapján: 

ENDPOINT - GET -> api/users/{username}

JSON: 	{

  	"id": number,
  	"username": "string",
  	"email": "string"

	}

-------------------------------------

Összes felhasználó lekérése (jelenleg publikus / vagy belső használat):

ENDPOINT - GET -> api/users/all

Válasz: UserDto lista (jelszavak kivételével!).

-------------------------------------

ENDPOINT - GET -> images/img.png

------------------------------------

AUTH FONTOS MEGJEGYZÉSEK:
- NEM KELL HEADER AUTH
-Nem kell token localStorage-ben
-Minden auth cookie alapú
-Fetch hívásoknál:
	js:
	- fetch(url, {credentials: "include"});

!!!!!!!! RENDELÉSEK (ORDERS): !!!!!!!!

Rendelés létrehozása:

ENDPOINT - POST -> api/orders

Feltétel:

- Bejelentkezett felhasználó (cookie → access_token)

{
  "address": "string",
  "items": [
    {
      "productId": number,
      "quantity": number,
      "price": number
    }
  ]
}

Válasz: 
{
  "success": true,
  "orderId": number
}

------------------------------------

Egy rendelés lekérése (frontend formátumban):

ENDPOINT - GET -> api/orders/{orderId}

Feltétel:

- Bejelentkezett felhasználó
- Csak a saját rendelés kérhető le

JSON válasz:
{
  "firstName": "string",
  "lastName": "string",
  "email": "string",
  "address": "string",
  "items": [
    {
      "id": number,
      "name": "string",
      "img": "string",
      "price": number,
      "quantity": number,
      "lineTotal": number
    }
  ]
}

------------------------------------

Felhasználó rendeléseinek listája:

ENDPOINT - GET -> api/orders

-Feltétel:
-Bejelentkezett felhasználó

JSON válasz:
[
  {
    "orderId": number,
    "address": "string",
    "createdAt": "2026-03-18T12:00:00"
  }
]

------------------------------------

HTTP VÁLASZOK:

200 -> Sikeres
201 -> Létrehozva
400 -> Hibás input
401 -> Hibás login
403 -> Nincs jogosultság/token
404 -> Rendelés nem található / nem a useré
